## SWE-bench Lite

| 顺序 | 工作 | 验收标准 |
| --- | --- | --- |
| 1 | 完成 Phase 2 的 `dev` 环境和基线。 | 补齐 23 题的可见测试和评分环境，保存每题基线、镜像、终态及评分证据。验证中断续跑与独立重评分，按预定题数统计。 |
| 2 | 完成 Phase 3 实验管理。 | 同题多个实验和尝试可独立查询，关联运行事件、用量、候选补丁及官方评分。能读取已有证据重新汇总。 |
| 3 | 推进 Phase 4 单项优化与消融。 | 固定模型、题目、评分器和总预算，逐项测试定位、失败反馈、上下文和预算分配，记录配对结果、用量和耗时。 |
| 4 | 完成 Phase 5 实验视图。 | 工作台按实验和题目检索运行轨迹、补丁、评分及失败原因，支持两组结果对照。 |

实验分组和正式 `test` 条件见[专题实施方案](EVAL_PLAN.md)，实际命令见[批量评测指南](EVAL.md#swe-bench-lite-批量评测)。

## 工作台后续验收

- **交付与恢复。** 演练 IDE 应用后回传验证证据，以及从 PostgreSQL 和状态卷的联合备份恢复原线程与 worktree。
- **线程与应用验证。** 从指定历史轮次创建独立线程，定义运行中补充要求的生效位置，在隔离环境管理开发服务并记录页面验证结果。
- **扩展与部署。** 明确 Web 加载 Skills、调用 MCP 和外部客户端接入的授权及生命周期；在实际组织身份源、HTTPS 和新平台上完成部署验收。
