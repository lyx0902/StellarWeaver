# StellarWeaver 项目文档

StellarWeaver 是一个本地 Coding Agent。它根据任务读取代码、提出并执行经授权的变更、运行项目检查并交付可审阅的结果。命令行 CLI 和浏览器工作台共用 Python Agent 循环，分别提供终端自动化与可交互的任务管理。

## 当前能力

| 能力 | CLI | Web 工作台 |
| --- | --- | --- |
| 模型与交互 | `chat` 交互、`exec` 单次运行、可见文本流式输出、JSONL；支持 DeepSeek 和离线 FakeModel。 | 按轮展示流式回复，保留任务时间线。同项目可在原线程追问。普通对话独立分组。 |
| 项目操作 | 枚举、读取和搜索文件，新建和精确编辑，执行命令，检查 Git 状态与差异。 | 在选定项目中运行只读或修复任务。侧栏按工作区组织会话，支持归档与恢复。 |
| 权限与预算 | 支持只读、询问和工作区编辑策略。校验工具参数、文件哈希与运行预算。 | 编辑与测试逐项审批，支持取消、运行额度、DeepSeek 日用量与审计。 |
| 测试和改动交付 | 使用 `/diff` 区分启动基线与会话增量。`/undo` 可撤销证据和当前文件匹配的内置编辑。 | 可配置验证命令，检查在一次性容器内执行。审阅改动块、导出补丁，并在新的独立工作区应用选中改动后重新验证。 |
| 会话与恢复 | SQLite 会话记录，支持列表、回放、导出和恢复。 | PostgreSQL 持久队列及事件流。刷新按游标补读，中断后展示待核对操作。 |
| 上下文与扩展 | 100,000 tokens 默认窗口配置，支持历史压缩、分目录 `AGENTS.md`、Python repo map、Skills 和本地 stdio MCP。 | 项目任务沿用共享上下文，输入框显示上下文用量和项目路径。普通对话关闭仓库上下文和工具。侧栏 Skills 库支持只读浏览明确配置的本机技能。 |
| 身份与部署 | 本机配置与当前操作系统用户权限。 | 本机 Compose 使用账号密码和会话 Cookie。可选团队配置支持 OIDC、成员角色和项目授权。 |

当前本机入口为 `http://127.0.0.1:8787/`，使用 DeepSeek。项目源目录只读挂载，线程在持久卷中的独立 Git worktree 内编辑。专用执行服务接收该线程的快照并启动验证容器。普通对话可直接从侧栏「新任务」开始。

## 一次修复的完整流程

选择 Git 工作区并发起修复。Agent 先读取相关文件，编辑前展示差异与审批卡。用户批准后，Agent 根据实际测试结果决定是否继续修复。任务结束后，工作台保留可展开的工具过程、测试退出码和补丁。用户选择需要的改动块，工作台即可基于同一提交创建审阅工作区并重跑配置的检查。

终端可用离线演示复现一次失败与修复。演示使用临时 Git 仓库，实际测试退出码依次为 `1`、`0`。

```powershell
uv sync --locked
uv run --offline python -m stellarweaver.demo
```
